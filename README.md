# BI DSDM Career Intelligence

Confidential prototype dashboard for DSDM career management.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

All records are dummy data. No external database or API key is required.

## Deployment

Upload `app.py` and `requirements.txt` to a GitHub repository, then deploy the repository using Streamlit Community Cloud. Select branch `main` and main file `app.py`.

> Do not upload real/confidential employee data or credentials to a public repository.
